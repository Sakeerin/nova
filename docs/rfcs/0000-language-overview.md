# RFC 0000: Nova Language Overview

**Status:** Informational  
**Date:** 2026

## Summary

Nova is a statically-typed, full-stack programming language with:

- Native AOT compilation (LLVM + Cranelift)
- Tracing garbage collection (MMTk)
- Hindley-Milner type inference + traits
- async/await concurrency (Tokio model)
- Built-in frontend (signals, WASM, SSR)
- Single-binary toolchain

See `00-MASTER-SPEC.md` for the complete specification.
